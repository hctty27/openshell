# OpenShell 多语言 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans for inline execution, or superpowers:subagent-driven-development only if the user chooses delegation. Steps use checkbox syntax for tracking.

**Goal:** 默认英文，在设置中即时切换简体中文并持久化，完整覆盖应用提示和 AI 默认回答语言。

**Architecture:** 前端使用 i18next + react-i18next 和内置语言包；Go preferences 保存语言。错误与状态使用稳定代码，前端负责翻译；普通 AI 请求读取当前语言，自动任务捕获启动语言。

**Tech Stack:** 现有 Go / Wails v2、SQLite、React 19、TypeScript、Vite、Vitest、Testing Library、Playwright；新增 i18next、react-i18next。

**Spec:** docs/superpowers/specs/2026-10-21-i18n-design.md（用户于 2026-10-21 确认）。

## Global Constraints

- 默认和回退语言为 en。首批支持 en、zh-CN；不自动检测系统语言。
- 语言选项始终显示 English 和简体中文，标签显示 Language / 语言。
- 语言独立于外观页的保存按钮，选择后立即保存并切换；保存期间禁用选择。
- 保存失败时保留原语言，并用原语言显示失败信息，允许重试。
- 不重建终端或断开 SSH，不清除标签、输入内容、命令提议或聊天记录。
- 不翻译用户数据、服务器输出或既有聊天记录。
- 保留现有紧凑布局及 30px 栏高。
- 语言包随安装包构建，离线可用。
- 不通过匹配中文句子判断错误类型。
- 合并与发布由后续明确指令执行。

## Review Focus

1. 旧配置、无效偏好、启动读取失败：默认英文或可重试，不闪错语言、不永久空白（任务 1、2）。
2. 双击选择、保存失败、其他设置刷新：无偏好竞态或未保存语言，不覆盖已保存值（任务 2）。
3. 弹窗队列和用户草稿：切换后当前和待显示弹窗都更新，草稿、焦点和未决 Promise 保留（任务 3）。
4. Wails 字符串 / Error 拒绝、未知错误和原始输出：可识别错误正确翻译，第三方详情不丢失（任务 4）。
5. 自动任务暂停恢复、流式回答与语言切换交错：固定任务语言，不重发命令，下一次普通请求采用新语言（任务 5）。

## 文件职责

- frontend/src/i18n/index.ts、languages.ts、types.d.ts：初始化、注册、资源类型。
- frontend/src/i18n/message.ts：应用文案描述及当前语言渲染。
- frontend/src/i18n/errors.ts：错误解码与错误 / 原因显示。
- frontend/src/locales/{en,zh-CN}/{common,sessions,settings,terminal,ai,errors}.json：对应领域语言包。
- language.go：Go 语言标准化及读取偏好；app.go / automatic.go 保留业务入口。
- internal/apperror/error.go：带错误码、参数和因果关系的错误及桥接信封。
- 既有组件、桥接和类型：接入翻译，不做无关重构。
