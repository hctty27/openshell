# OpenShell 稳定性专项验收（v0.1.47 基线）

## 范围

本阶段不新增协议和界面功能，验证 SSH 生命周期、Windows ConPTY、本地终端、xterm.js、SFTP / ZMODEM 的可靠性。
GitHub CI、Go race detector、Windows Wails 编译以及浏览器模拟测试属于**自动化检查**，不能替代打包程序的真实 Windows 操作。

## 自动化门禁

- `go test -race ./...`：覆盖 Go 并发访问、SSH 连接代次与取消、终端写入/历史、SFTP 集成测试。
- `go vet ./...`：检测可静态发现的 Go 代码问题。
- `npm run build`、`npm test -- --run`、Playwright：确认 React 状态与终端布局回归。
- `Windows terminal smoke`：原生 Windows 编译、Go 测试、图标和 ZMODEM 资源检查。已将本地 ConPTY 和 `App.tsx` 列入改动触发范围。
- PR CI 完成前不合并；自动化通过并不意味着下面的手工场景已验收。

## Windows 实机手工矩阵

| 场景 | 操作 | 通过标准 |
| --- | --- | --- |
| 基础 SSH | 密码、密钥、首次主机指纹、错误密码、断开后重连 | 凭据不会串到其他会话；重试状态清晰 |
| 长连接 | 保持 SSH 连接与本地 PowerShell 各运行 24 小时 | 无无故断开、死锁、显著增长的内存占用 |
| 多标签 | 同时连接 10 个会话，重复切换、关闭、快速重连 | 输入与输出不串台，不重复创建连接，不产生僵尸 PTY |
| SSH 断网 | Wi-Fi 断开、VPN 切换、服务器主动退出 | 遵守自动重连与本地 Shell 回退设置；不会执行旧连接命令 |
| ConPTY | SSH `exit`、点击断开、连续重连、关标签 | 本地 PowerShell/CMD/WSL 可输入、可退出，未留下残存进程 |
| 交互程序 | vim、top/htop、tmux/screen、Claude Code、Codex | 颜色、光标、粘贴、鼠标、中文 IME、窗口改变和 Ctrl+C 正常 |
| 分屏渲染 | 两分屏间反复切焦点、调整分割比例、缩放窗口 | 不闪烁、不变字号、没有末行裁切、滚动条不挤占文字 |
| 大量文本 | 在测试目录运行 `seq 1 100000`；滚动并搜索 | UI 保持响应，终端最后一行可见，不因输出断开 SSH |
| SFTP | SSH 终端同时运行时上传/下载用户准备的测试文件 | 文件校验一致，关闭面板不误取消任务 |
| SFTP 中断 | 上传中断、续传、目标文件被其他程序修改 | 校验不匹配时拒绝错误续传，状态不误报成功 |
| ZMODEM | `rz` / `sz` 单文件与批量文件、取消、断线 | 协议数据不混进终端日志，取消状态明确，无文件静默损坏 |
| 资源与升级 | 比较启动、10 标签、关闭所有标签后的进程资源；从前一版升级 | 内存趋于稳定，旧会话及配置保留 |

**注意：** 24 小时稳定性、真实 GUI 交互、Windows 输入法和大文件传输必须在 Windows 主机上验证。任何未执行的项目都应标记为「未验证」，不能仅凭 CI 成功宣称通过。

## 建议的记录格式

每次验收记录操作系统版本、OpenShell Git SHA、WebView2 版本、服务器系统、是否经过 VPN/跳板、步骤、预期、实际结果及日志；如发现异常，附能复现问题的最短步骤。
高 CPU/内存问题记录空闲与运行时的进程 Working Set/CPU，而不是只看一个时间点。

## 通过条件

1. 所有自动化门禁通过。
2. 实机矩阵无阻断级缺陷；失败场景能明确给出错误且不会误报成功。
3. 没有 SSH 会话混淆、跨标签输出、错误执行目标、文件覆盖或凭据泄漏。
4. 发布前在目标 Windows 版本做安装版和便携版各一次回归。
