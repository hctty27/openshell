# 共享对话记忆验收记录

日期：2026-10-22；分支：`feat/conversation-memory`。

推送授权：用户已明确允许推送该功能分支；不包含主干合并或版本发布。

## 实现结果

每个服务器拥有多条持久化 AI 对话。同服务器的 SSH 标签共享列表，各自选择对话；选择同一对话时同步消息。新增、重命名、删除、分页及共享清空均有界面入口。连接归属使用实际服务器配置；恢复历史不会恢复命令执行权限。正在运行的对话仅允许发起标签控制。

默认启用保存与自动摘要，可在设置中关闭。关闭保存后使用共享临时集合，不会把临时记录自动写回磁盘。摘要保留原始历史，按真实请求 JSON 字节预算控制上下文。

## 独立审查

一次整分支审查提出六项 Important 问题，均已修复并添加回归：

1. SSH 断开通知不再同步等待自身操作；显式关闭仍等待清理。
2. 自动任务 ID 与执行上下文原子注册，取消后不能启动旧任务。
3. 命令提案注册、修改和取消校验同一运行，旧回调不能复活提案或影响新运行。
4. 消息按自身序号合并，较晚收到的独立消息不会被后续运行事件丢弃。
5. 标签选择使用服务器选择版本、连接代次和请求世代；迟到列表和快照不会复活删除项或切回旧选择。
6. 恢复时未配对的工具调用显示明确的“结果未知”，没有执行按钮，不自动重试。

没有 Critical 问题或延期处理的 Minor 问题。

## 实现取舍（Rulings I made）

以下列出执行期间全部十项取舍及成本：

1. 使用新克隆及关联 worktree 隔离实现；属于已授权的可逆准备工作，成本是保留一个工作目录。
2. 技能辅助脚本不可执行，改用已批准计划和手动任务记录；成本是手动维护验证与提交记录。
3. 消息采用有索引的 JSON 载荷，按对话/序号与唯一消息 ID 检索；未来格式变化可能需要迁移。
4. 增加事务性删除与选择替代对话的存储函数，保证最后一条删除的原子性；成本是额外存储接口。
5. 服务用一把短操作锁串行处理 SQLite 元数据，模型和 SSH 网络调用不持锁；不同服务器元数据可能短暂互等。
6. App 聊天与命令逻辑拆入专用文件；成本是文件数量增加。
7. 取消在释放运行所有权前保存并清理在途操作；显式停止/关闭可能短暂等待，SSH 断开通知走非阻塞路径。
8. 保留最近六个完整轮次及当前进行中的轮次；相比六轮总数，使用稍多上下文。
9. 流事件发送累计脱敏文本，使用逐消息序号/版本和独立选择版本合并；成本是事件字节数和状态元数据增加。
10. 浏览器桥接替身与真实 Go SSH/SSE 集成测试分别验证界面和执行；原生 Windows 打包界面仍需人工验收。
